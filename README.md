# 地形あて

山の名前・高さ・都道府県を読んで、地図の4つの▲からその山を当てる1日5問のゲーム。遊ぶうちに日本の山と都道府県の場所が身につきます。

- 遊ぶ: https://satou-aaaaa.github.io/chikei-ate/
- 今日の5問（やさしい2・ふつう2・むずかしい1）はだれでも同じで1日1回。上級（都道府県の名前が出ない地図で3問・ヒントなし）、練習（何度でも・地方を選べる）、とことん（何山続けて当てられるか）、当てた山が地方ごとに集まる「山の手帳」があります。
- まちがえても選び直せます。まちがえた▲がどの山だったかも教えます。ヒントは「その山の都道府県をぬる」→「▲を2つにしぼる」の2段です。時間制限はありません。
- 機種を変えるときは「引き継ぎ」で、記録をコードと QR にして移せます。

## データの出どころ

- 山の名前・よみ・高さ・場所・都道府県：国土地理院「日本の主な山岳標高（1003山）」2026年3月31日版を加工して作成（<https://www.gsi.go.jp/kihonjohochousa/kihonjohochousa41139.html>）。国土地理院コンテンツ利用規約に従い、出典を書いて使っています。峰がいくつもある山（同じ索引番号）は、いちばん高い峰を1つの山にまとめています。元の表は `tools/gsi-1003zan-20260331.csv`。
- 都道府県の形：Natural Earth（パブリックドメイン、<https://www.naturalearthdata.com/>）を簡単にしたもの。小さな島は省いています。

## 記録と通信

記録は遊ぶ人のブラウザにだけ残り、ゲームから自動で外へ送ることはありません。例外は2つ：文字（Google Fonts）を読み込むとき、まだ端末に保存が無ければ Google に IP アドレスが届きます。「Xで投稿」「LINEで送る」「結果をシェア」を押したときだけ、結果の文が選んだ先に渡ります（山の名前＝答えは入りません）。

## 開発

```bash
bash scripts/setup.sh   # 最初に一度
node qa/run.mjs         # 検査（CI と同じ）
```

山のデータは `node tools/make-data.cjs`、地図は `node tools/make-map.cjs <Natural Earth の admin_1 の GeoJSON>` で作り直せます（決まりは AGENTS.md）。
